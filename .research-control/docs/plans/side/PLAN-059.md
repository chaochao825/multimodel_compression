# PLAN-059: Test support-state interaction before reader deployment

- Status: complete
- Owner: researcher and Agent
- Gate: G-029
- Claim: C-029
- Candidate line: L-029
- Lane: explore side probe
- Resource cap: existing capture plus one A800 for Stage 0; no H200 before a
  task-valid Stage 1 result

## Objective

Determine whether regular exact support can be chosen to make the remaining
open-query visual measure substantially more representable by the same
mergeable state, rather than merely preserving large attention mass.

## Steps

1. Validate the control-variate N/Z algebra and exact-recovery invariant.
2. Run the target-visible Stage-0 four-arm capacity comparison on exposed
   development captures.
3. If and only if Stage 0 passes, freeze a calibration-only page router and run
   the deployable factorial comparison.
4. If and only if local transfer passes, evaluate task logits, agreement,
   harmful flips, and path consistency.
5. If and only if task guards pass, measure equal-latency H200 Pareto including
   writer, router, retrieval, state, correction, and fallback.
6. Close G-029 or propose untouched confirmation without changing L-026.

## Stop rule

Stop immediately on a valid Stage-0 capacity miss. Do not compensate with more
feature width, irregular token support, target-trained router, confirmation
identities, or heuristic fallback. Classify implementation failures separately
and use at most two repairs per stage.

## Closure

EXP-050 completed as a fixed-state boundary. Residual-aware support produced a
large paired interaction but the protocol had frozen the whole-measure state,
so it could not answer the explicitly required jointly trained factorial cell.
RDR-034 preserves the result and opens PLAN-060 / EXP-051 without changing
width, density, data, endpoint, or the Wan mainline.
