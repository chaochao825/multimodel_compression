# PLAN-NNN: Outcome-oriented title

- Status: draft
- Owner: researcher and Agent
- Gate: G-NNN
- Claims: C-NNN
- Candidate line: L-NNN
- Lane: explore | prove | integrate
- Resource cap: define a hard cap

## Decision to unlock

Name the one decision this plan will make possible.

## Context and source authority

List the exact project records, accepted RDRs, protocols, code identity, data identity, and configuration identity.

## Non-goals

State what this plan will not pursue.

## Milestones

Each milestone must end in evidence or a decision, not merely activity.

## Validation

Define mechanical checks, scientific acceptance thresholds, falsifiers, and reproducibility requirements.

## Stop and escalation rules

Stop at the cap, on protocol invalidation, or when the planned decision can already be made. Escalate any proposed change to protected human decisions.

## Closure

Update the result record, experiment registry, claim state, candidate state, `STATUS.md`, and accepted decision record if needed.
