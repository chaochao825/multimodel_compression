## Question

Does the low offline temporal rank left by `EXP-000` come primarily from
channel-wise, token-row-wise, or joint heterogeneity that a single scalar AR
transition cannot express?

## Evidence status and independence

- Evidence tier: post-hoc audit on the same EXP-000 identities.
- Input: the 16 deterministic sampled token rows already stored in each F81
  capture cell; no new model run and no full-tensor claim.
- Calibration/held-out split remains unchanged. Held-out outcomes were already
  exposed by EXP-000, so no positive result can confirm or promote C-001.

## Methods

Fit AR(3)+current-input-innovation with four coefficients per group under:

- one scalar group;
- channel groups of width 256, 64, and 16;
- one group per sampled token row;
- sampled-row x channel-64 joint groups.

For every granularity compare calibration-only stage coefficients and a
per-sample target-leaking oracle. Evaluate anchor-reset H1/H2 on the same target
steps and report sample-output relative L2, cell pass coverage, coefficient
payload, and plots.

## Outcome mapping

- No potential: even the row x channel-64 oracle fails 1% aggregate / 2% worst
  at H2; stop grouped state.
- Dynamic boundary: oracle passes but calibration-only coefficients fail; the
  missing object is a content-conditioned coefficient generator.
- Static boundary: calibration-only channel or row grouping passes on sampled
  rows; preregister a fresh full-tensor/untouched-identity Gate before any claim.
- Invalid: sample shapes differ, identity split changes, or target leakage is
  mislabelled as deployment evidence.

## Resource cap and stop rule

One CPU analysis over existing artifacts. No new H200 capture, no threshold
tuning, no rollout, and no kernel. Stop after the registered granularities.
