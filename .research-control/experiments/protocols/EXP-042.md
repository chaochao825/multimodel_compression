# EXP-042: Motion-conjugated finite-horizon flow-curvature Gate

- Status: accepted and running; development midpoint-RK2 teacher Gate only
- Claim: `C-021`
- Candidate: `L-021`
- Gate: `G-021`
- Lane: explore
- Resource scope: no fixed GPU-hour ceiling; one frozen staged pass through
  development, calibration, validation, and conditionally unlocked test

## Decision question

Does motion alignment computed only from Wan's current clean-latent prediction
make the same small nonperiodic finite-horizon curvature operator materially
more accurate and transferable than its unaligned counterpart?

## Artifact audit and need for fresh capture

- Canonical historical results contain `2741` files, including `58` names with
  `latent` or `trajectory`, eight `final_latent.pt` files, and large QKV replays.
- No per-step latent/state file and no index jointly identifying state, time, and
  guided model velocity was found. Tensor payloads were not loaded for this
  audit.
- The 72 full-QKV F81 captures were generated on 20-step UniPC CFG paths. Wan's
  UniPC implementation stores past converted model outputs and a last sample;
  its state transition is not a Markov function of current `z_t` alone.
- These artifacts remain valid for their registered attention claims but cannot
  define the finite-interval flow curvature in this protocol. A minimal fresh
  Euler trajectory capture is required; no QKV or block activation is captured.

## Frozen model and numerical coordinates

- Model: Wan2.1-T2V-1.3B, 81 frames, 480 by 832, BF16 model execution, FP32
  latent state update, FA3 BF16 self-attention, dense SDPA cross-attention.
- Guidance: original conditional/unconditional CFG arithmetic at scale 5.0.
- Flow coordinate: normalized sigma, not a UniPC step index. With base
  `s_j = 1 - j/N`, use `sigma_j = 5 s_j / (1 + 4 s_j)`.
- Teacher: explicit Euler with 100 intervals. Save only states at indices
  `0,25,50,75,100` and guided velocities at `0,25,50,75`.
- Update: `z_{j+1} = z_j - (sigma_j - sigma_{j+1}) v_j`.
- Current clean prediction: `x0_hat = z_j - sigma_j v_j`, matching Wan's
  `flow_prediction` conversion.
- Development-only convergence rule: compare Euler-100 with Euler-200. Use 100
  if endpoint relative L2 is at most 0.25%; otherwise use 200 if at most 0.5%.
  A larger discrepancy is an engineering failure, not a scientific null.
- UniPC remains the production quality reference for later rollout and is not a
  source of curvature labels.

## Exact target

For coarse interval `t > r`, let `delta = sigma_t - sigma_r`:

    u_star = (z_t - z_r) / delta
    kappa_star = (u_star - v_t) / delta
    z_r = z_t - delta v_t - delta^2 kappa_star

No small-interval numerical substitution is needed because the shortest frozen
coarse interval is bounded away from zero. All target arithmetic is FP32.

## Observable motion and oracle separation

- Deployment arm estimates adjacent latent-frame displacement from current
  `x0_hat` using block normalized cross-correlation, a four-latent-pixel search
  radius, four-by-four query blocks, forward/backward consistency, and bilinear
  nonperiodic sampling. Round-trip displacement must be at most one latent pixel.
- For target frame `tau`, only neighboring features are transported into the
  target coordinate: `tau-1 -> tau` and `tau+1 -> tau`. There is no long-chain
  flow composition and no first/last-frame wrap.
- Invalid and occluded samples are masked; invalid fraction and boundary-only
  error are mandatory outputs.
- The target-exposed capacity arm computes the same displacement rule from the
  terminal teacher clean latent. It may not select a deployable model, checkpoint,
  interval, regularizer, or fallback.
- Physical-video displacement is a coordinate prior. It is never called the
  denoising probability-flow velocity.

## Frozen operator and controls

- Treatment: a 32-channel bottleneck nonperiodic motion-aligned 3D lifting
  applied to current clean prediction and guided velocity. It concatenates
  temporal offsets `-1,0,1`, then applies a `96 -> 32` three-by-three spatial
  projection, SiLU, and `32 -> 16` pointwise projection. This is a bottleneck
  width, not a claimed matrix rank above the 16-channel output dimension.
- Unaligned control: identical parameters, training, stencil, payload, and
  evaluator with identity transport.
- Raw-noisy control: identical structure using raw latent coordinates.
- Capacity control: same architecture with target-exposed motion only.
- Same-budget local control: `96 -> 251 -> 16` pointwise channel mixing plus a
  three-channel `3 -> 16` pointwise path, exactly matching the structured arm's
  28,160 trainable weights and per-position multiply count.
- Boundary control: circular padding/BCCB embedding with the same coefficients;
  it is a negative control and cannot rescue a failed nonperiodic arm.
- Calibration optimizer, steps, seed, checkpoint period, and validation selection
  are frozen in `motion_conjugated_flow_curvature_exp042_v1.json`.
- Do not add rank, experts, sparse residuals, cache, fallback, or a new warp
  family after observing validation or test outcomes.

## Metrics

- Primary local metric pools squared curvature errors with `delta^4`; this is
  exactly the local endpoint-displacement scaling, not a full Jacobian certificate.
- Primary endpoint metric composes four predicted corrections while replaying
  frozen teacher velocities/features. This is explicitly an open-loop
  frozen-field replay, not a closed-loop generation claim.
- Report aggregate and worst identity endpoint relative L2, per-interval error,
  finite-map composition defect, warp invalid fraction, boundary-only error,
  parameters, MACs, payload bytes, and measured standalone adapter latency.
- Full rollout, SSIM, VBench, and end-to-end H200 speed remain prohibited until a
  separate accepted Gate.

## Outcome map

- `capacity-null`: target-exposed aggregate/worst endpoint error exceeds
  0.5%/1%. Stop without opening deployable transfer.
- `alignment-null`: capacity passes but current-observable alignment improves
  displacement-weighted curvature error by less than 25% versus the identical
  unaligned structure.
- `transfer-null`: observable alignment passes its relative-gain gate but frozen
  aggregate/worst endpoint error exceeds 1%/2%.
- `cost-null`: quality passes but measured adapter cost exceeds 10% of one Wan
  NFE or the warp has no bounded fused implementation.
- `motion-conjugated-curvature`: all gates pass. This authorizes only a new
  frozen-backbone tiny-adapter training and closed-loop rollout decision.
- `invalid`: identity leakage, early test access, hash drift, post-outcome family
  change, target-exposed deployable fitting, or solver-coordinate mismatch.
- `engineering-failure`: capture/schema/numerical failure before a valid metric.

## Resource and execution guards

- Run conditional and unconditional branches on the two H200s in parallel.
- Store five FP32 states and four FP32 guided velocities per identity. Do not
  decode the VAE and do not capture QKV, attention, or block activations.
- Hash every payload and manifest. Record model weight, Wan solver source,
  prompt plan, config, capture code, evaluator code, CUDA, PyTorch, GPU, and Git
  identities before validation access.
- Store fresh tensor payloads under `/opt/data` and keep their total below 5 GiB.
- Stop on the first valid registered outcome or protocol invalidation. Engineering
  repairs are allowed before a valid development result when fully logged and
  when they do not change the endpoint, identities, method family, or thresholds.
- The researcher accepted this protocol in RDR-0022. Capture/evaluator identities
  are frozen in `motion_conjugated_flow_curvature_exp042_implementation_freeze.json`;
  PLAN-047 found a valid but nonconverged shifted-grid teacher. RDR-0023 and
  PLAN-048 authorize a development-only uniform flow-sigma diagnostic; no later
  split is unlocked by this diagnostic alone.
