# EXP-004: Structure-as-risk-scout screen

## Decision question

Can linear-cost post-RoPE Q/K/V structure statistics select among a small set of
existing centroid/moment attention actions and dense fallback, with no held-out
fitting, while meeting the local 1%/2% quality gate and a 1.5x arithmetic
whole-attention threshold?

## Frozen feature families

All learned scores use calibration rows only. Validation may select one global
acceptance threshold per feature family. Test rows are read only after model,
standardization, action set, and threshold are frozen.

1. `static`: calibration error table indexed by layer, step, head, and action.
2. `mass`: static categorical identity plus the existing
   `router_selected_mass_proxy`.
3. `norm`: static identity plus Q/K/V norm dispersion, outlier ratio, and top-1%
   energy leverage.
4. `structure`: static identity plus contiguous/spatial SICS, axis-neighbor
   cosine, finite-difference energy, and same-token Q/K cosine.
5. `full`: the union of mass, norm, and structure features.

The learned families use fixed ridge regularization on log local output error.
No dense attention mass, dense AV, target residual, head-role label, test error,
adaptive SVD, or retrospective feature choice is legal as an input.

## Policy and endpoints

For a frozen score threshold, each head-cell chooses the lowest-work eligible
action; otherwise it executes dense attention. The threshold is the validation
point with maximum arithmetic speed that satisfies:

- selected aggregate output relative L2 at most 1%;
- every selected record output relative L2 at most 2%;
- at least 5% selected coverage.

Primary test endpoints are aggregate and worst selected error, false-safe count,
coverage, fallback-adjusted arithmetic attention speedup, and gain over the
strongest static or mass-only baseline. A target-leaking Lagrangian action
envelope is reported only as a function-class ceiling. Arithmetic work excludes
feature extraction, routing, gathers, launches, and kernel inefficiency and is
not an H200 speed claim.

## Outcome mapping

- `pass`: the frozen full scout has zero false-safe records, test aggregate/worst
  error at most 1%/2%, arithmetic attention speedup at least 1.5x, and at least
  0.05x gain over the strongest static or mass-only baseline. Open only a fresh
  feature-cost and fused-worker timing protocol.
- `boundary`: the target-leaking multi-action envelope reaches 1.5x but no frozen
  scout does. Stop train-free routing; a learned router requires a new decision.
- `null`: even the target-leaking envelope is below 1.5x, or structure features
  do not improve on static/mass selection. Stop this route.
- `adverse`: validation passes but test violates the 2% worst guard or exhibits
  any non-finite output. Stop without threshold relaxation.
- `invalid`: split overlap, missing or duplicate records, source/config mismatch,
  test-dependent fitting, illegal feature access, stale output reuse, or data
  integrity failure. Repair once before inspecting scientific outcomes.

## Budget and stop rule

One linear-cost feature extraction pass over the 36 existing conditional QKV
captures, one frozen analysis, and one pre-outcome engineering repair. No new
model generation, training, attention kernel, or rollout is allowed. Stop after
classifying `G-004`.
