## Decision question

At a bounded active-memory cost, does selecting regular exact pages to reduce
the residual error of a mergeable bulk state produce a real interaction gain
over independently trained support and state?

The visual measure is represented by a control variate:

\[
\widehat N_\Omega=\widehat N_{all}
+\sum_{g\in\Omega}(N_g^{exact}-\widehat N_g),
\qquad
\widehat Z_\Omega=\widehat Z_{all}
+\sum_{g\in\Omega}(Z_g^{exact}-\widehat Z_g).
\]

All arms use shared numerator/denominator normalization.

## Stage 0: capacity and interaction ceiling

Use the same calibration-trained whole-measure state checkpoint for all arms:

1. `exact_only_mass`: exact mass-selected pages, no bulk state.
2. `state_only`: the additive state, no exact pages.
3. `independent_mass_correction`: the state plus exact correction of the
   mass-selected pages.
4. `joint_residual_oracle`: the same state plus exact correction of pages
   selected by target-visible reduction of the current state residual.

Arms 3 and 4 have identical active payload and correction algebra. Their only
difference is whether support is aligned with the state's residual. Selection
uses seven rounds of 14 pages, totaling 98 of 392 pages.

Stage 0 passes only if the joint arm has all:

- 72 complete development sample-layer cells;
- visual mean/P95/worst relative L2 at most 0.5%/1%/2%;
- paired position-bootstrap lower 95% bound for risk improvement over the
  independent arm at least 25%;
- analytic active-state compression at least 3x;
- finite outputs, exact page budget, and exact recovery when every page is
  corrected.

A miss is a valid capacity no-go and closes EXP-050 before router training.

## Stage 1: deployable four-arm comparison

This stage is authorized only by a Stage-0 pass. It freezes one regular-page
router using calibration identities only. Router inputs may use the current
query and stored page summaries, but not tokenwise QK scores, dense attention,
target output, answer label, or development fitting.

The four arms are trained with equal data, optimizer steps, random seeds, and
model-freeze policy. Joint and independent arms use identical density, width,
storage, and page-scoring architecture. `Independent` freezes a support scorer
trained without state-residual targets before fitting the state. `Joint`
alternates or jointly optimizes the page scorer against shared N/Z residual
risk.

The primary comparison is paired task risk and local visual risk for joint
versus independent. Exact-only and state-only remain factorial ablations.

## Stage 2: task and system Gate

Only a Stage-1 local pass authorizes frozen full-reader intervention. The dense
teacher first-token distribution, answer margin, and ground-truth multiple
choice accuracy are measured without opening confirmation.

Only a task pass authorizes isolated-H200 timing. Each arm is tuned to a
latency frontier; equal-latency comparisons include page scoring, retrieval,
state read, exact correction, shared normalization, writer amortization at one
and five questions per video, and fallback. Analytic compression is diagnostic
only.

## G-029

The development Gate passes only if joint support-state satisfies all:

- paired task-risk improvement over the best equal-latency independent arm at
  least 25%, with bootstrap lower 95% bound above zero;
- dense-answer agreement at least 98%;
- zero harmful flips where dense is correct and joint is wrong;
- merge-order/path consistency relative error below 1%;
- active-state compression at least 3x;
- local visual mean/P95/worst no worse than 1%/2%/5%;
- measured H200 latency no greater than the matched independent arm.

Only a complete G-029 pass may propose positions 97--120 confirmation. It does
not automatically authorize confirmation or alter the Wan mainline.

## Engineering validity and stop rule

Before interpreting a miss, require dense replay, exact-page budget, all-page
exact recovery, merge-order equivalence, hard-mask evaluation, finite rows, and
method-specific gradient-flow tests. Preserve failed attempts. At most two
implementation repairs are allowed per stage without changing scientific
identities.

Stop on one valid no-go/pass for the current stage, leakage, identity drift,
two failed repairs, resource exhaustion, or user interruption. Stage 0 uses
existing captures and one A800. H200 is not used until Stage 2.
